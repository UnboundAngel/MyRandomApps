# Midnight Writer

A distraction-free, atmospheric writing environment designed for deep focus and late-night inspiration.

## Features

- **Immersive 3D Interface**: A beautiful virtual desk with a leather-bound journal.
- **Zen Mode**: Enter a state of flow with a minimal interface and optional fullscreen immersion.
- **Thematic Ambiance**: Integrated soundscapes like crackling fire, gentle rain, and city nights.
- **The Oracle**: Break through writer's block with atmospheric inspiration prompts.
- **Typewriter Scrolling**: Keep your focus locked with vertically centered active lines.
- **Ink Flow Mode**: A drafting tool that disables the backspace key to maintain forward momentum.
- **Candle Sprint**: An atmospheric timer to keep you writing for set durations.
- **Analytics**: Track your progress with word counts and writing streaks.
- **Themed Export**: Save your work as Markdown, Plain Text, or themed PDFs that preserve the app's aesthetic.

## Shortcuts

- `ALT + Z`: Toggle Zen Mode
- `ALT + O`: Open The Oracle
- `ALT + L`: Return to Library
- `ALT + S`: Open Settings
- `ALT + H`: Open Help
- `CTRL + S`: Force Save (Auto-saves by default)
- `ESC`: Close Modals / Exit Zen Mode
